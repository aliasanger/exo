# exo


This project includes code related to **Microbial exoenzymes promoted the transition to an oxygenated Earth** by Sanger et al. 2026 

exo/biogeochemical_model contains

[box_model_DOC_MC.m](https://github.com/aliasanger/exo/blob/06ebd47771a1d02984aa92ad1ede687b815a9775/biogeochemical_model/box_model_DOC_MC.m) by Mojtaba Fakhraee. It is set to run stochastically. 
& 
[UV Radiation](https://github.com/mbayder/UV_Radiation_Research_Updated) by Maria Bayder (mbayder). 


exo/genome_survey contains several scripts with flags (does not include data parsing scripts)
